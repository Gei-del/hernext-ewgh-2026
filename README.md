# ReStart Compass

**Your path still counts.**

ReStart Compass is a focused planning tool for women returning to work, changing
careers, or pursuing a first formal role. It turns lived experience and practical
proof into a professional positioning statement, a realistic one-week plan, and
an explainable opportunity choice.

Built from scratch during the Elevate Women Global Hackathon 2026 by ByteNova.

## Core flow

1. Describe a target direction and nonlinear path.
2. Choose realistic weekly availability.
3. Select verifiable proof points.
4. Generate and complete a focused plan.
5. Choose one synthetic opportunity to pursue.

## Run locally

```bash
npm install
npm run dev -- -H 127.0.0.1
```

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Technology and privacy

Next.js 15, React 19, TypeScript, and CSS. The prototype runs entirely in the
browser, requires no account, and transmits no personal information. All visible
candidate and opportunity records are synthetic.
